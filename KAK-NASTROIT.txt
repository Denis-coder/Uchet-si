1. ЗАЛИТЬ НА GITHUB
-------------------
• Откройте репозиторий Denis-coder/Uchet-si
• Удалите старые файлы в корне (index.html, sw.js и т.д.),
  либо замените их файлами из этого архива.
• Залейте ВСЕ файлы из архива в КОРЕНЬ репозитория
  (index.html, css/, js/, иконки, sw.js, .nojekyll, …).
• Сайт: https://denis-coder.github.io/Uchet-si/
• Обновите страницу с Ctrl+F5 (или очистка кэша в Chrome).


2. ВЫ (АДМИН) — ПЕРВЫЙ ЗАПУСК
-----------------------------
• Откройте сайт на телефоне или ПК.
• Пользователей ещё нет → экран «Создайте администратора».
• Введите имя и пароль → «Создать администратора».
• Запомните пароль.


3. ОБЩАЯ БАЗА (токен один на бригаду)
------------------------------------
• GitHub (под Denis-coder) → Settings → Developer settings
  → Personal access tokens → Fine-grained tokens → Generate.
• Имя: Учёт СИ бригада. Срок — подольше (год).
• Only select repositories: Uchet-si
• Permissions → Contents: Read and write
• Generate → СРАЗУ скопировать (github_pat_…). Повторно не покажут.
• НЕ кладите токен в файлы репозитория и не публикуйте в чатах.

• В приложении вкладка «База»:
  - владелец: Denis-coder
  - репозиторий: Uchet-si
  - ветка: main
  - файл: si-journal.json
  - вставьте токен → «Сохранить настройки»
  - загрузите Excel (вкладка «Журнал» → Excel)
  - вернитесь в «База» → «Опубликовать на сайт»

В репозитории появится si-journal.json — это общая таблица + пользователи + история.


4. РАБОТНИКИ (логины)
---------------------
• Вкладка «Люди» (видна только админу):
  логин, ФИО, пароль → «Создать».
• Снова «База» → «Опубликовать на сайт» (чтобы логины ушли на все телефоны).

Каждый работник на своём телефоне:
1) Открыл тот же сайт
2) «Загрузить общую базу с сайта» (на экране входа) ИЛИ после входа «База» → «Загрузить»
3) Вход: свой логин + пароль
4) Один раз вставить ТОТ ЖЕ токен бригады в «База» → Сохранить
   (иначе правки останутся только на его телефоне)

GitHub-аккаунт работнику НЕ нужен.


5. КАК РАБОТАЕТ КАЖДЫЙ ДЕНЬ
--------------------------
• Смотреть перечень — можно после входа (или после загрузки базы).
• Править / добавлять / удалять — под своим логином; в «Истории» видно кто и что.
• Раз в ~25 сек приложение само подтягивает более новую версию с сайта.
• Не правьте одно и то же СИ одновременно с двух телефонов — останется последний.
• «Сохранить» (Excel) — запасная копия на устройство.


6. ЕСЛИ КТО-ТО УВОЛИЛСЯ
-----------------------
• Удалите токен в GitHub и создайте новый.
• Вставьте новый токен на рабочие телефоны.
• Старый токен перестанет писать в репозиторий.


7. PWA (как приложение)
-----------------------
Android Chrome: меню ⋮ → «Установить приложение» / «На экран „Домой“».
