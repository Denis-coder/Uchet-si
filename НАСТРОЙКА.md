# Как обновить сайт

1. Замените файлы в корне репозитория содержимым архива. Файл `si-journal.json` и папку `data/` не удаляйте, если они уже есть: там таблица и люди.
2. Положите ваш исходный Excel как `source/perechen.xlsx`. Без него сайт соберёт простой файл без оформления.
3. GitHub → Settings → Secrets → Actions → New secret.
   - Имя: `VAPID_PRIVATE_KEY`
   - Значение: ключ, который вам выдан отдельно. В репозиторий его не кладите.
4. Actions → Excel → Run workflow один раз, когда `data/` уже есть. Дальше файл собирается сам через полторы минуты после правки.
5. В приложении, вкладка «База»: вставьте новый токен GitHub и нажмите «Создать фразу и спрятать токен». Фразу запишите. Старый токен на GitHub удалите.
6. На остальных телефонах один раз введите эту фразу и нажмите «Открыть токен фразой».
7. «Включить уведомления» на каждом телефоне, где нужен сигнал при закрытом приложении. Сайт должен быть добавлен на экран «Домой».

Сворачивание истории (Actions → Squash history) само не запускается. Не нажимайте его, пока обычные правки не походят неделю. Если кнопка ругнётся на права, создайте второй токен с правом Contents и положите его в секрет `SQUASH_TOKEN`.
