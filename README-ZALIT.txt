Учёт СИ — залить в GitHub Pages

Почему прошлый сайт был белым и Excel не открывался
В репозиторий не попала папка assets (стили и скрипты).
Плюс пути были от корня домена (/assets/...), а сайт открывается
как https://denis-coder.github.io/Uchet-si/

Этот архив другой: стили и программа ВШИТЫ в index.html.
Отдельная папка assets больше не нужна.

Что сделать
1. Удалите старые файлы в репозитории Uchet-si (index.html и остальные).
2. Залейте ВСЁ из этого архива в корень репозитория.
3. Подождите минуту, обновите страницу с Ctrl+F5:
   https://denis-coder.github.io/Uchet-si/
4. Должен быть ТЁМНЫЙ экран, не белый.
5. «Указать файл Excel» — выбираете .xlsx, журнал открывается.
6. На телефоне: Chrome → этот адрес → ⋮ → Установить приложение.
